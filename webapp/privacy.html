隱私權與語音／圖片記帳說明

最後更新：2026 年 9 月 12 日

語音記帳採「先轉錄、再確認」流程。辨識模糊、失敗、超過每日上限或未經確認時，一律不會寫入帳本。

語音如何處理

  • 你在 LINE 傳送的語音，會由本服務從 LINE 下載到後端記憶體，並送往 OpenAI Audio Transcription 轉成文字。
  • 原始音訊只在處理期間存在於記憶體，不寫入本服務的磁碟或資料庫。
  • 轉錄文字與候選帳目會加密暫存最多 30 分鐘。只有你按下「確認記帳」後，交易才會寫入帳本。
  • 確認後，轉錄文字與來源資訊會加密保存在帳目中，最長保存 1,095 天，或在你主動刪除資料時提前移除。

第三方服務

語音轉錄會使用 LINE Messaging API 與 OpenAI API，因此相關資料會由這些服務依其政策處理。OpenAI 說明 API 資料預設不會用於訓練模型，除非客戶主動選擇分享；實際處理仍以 OpenAI 當時的官方政策為準。請參閱 OpenAI API 資料控制說明及 OpenAI 商業資料隱私說明。

同意、限制與停用

  • 第一次使用前，必須在 LINE 輸入「啟用語音記帳」，閱讀告知後再按「同意並啟用」。
  • 每位使用者每日最多送出 30 次語音轉錄，於台灣時間每日重新計算。
  • 你可隨時在 LINE 輸入「停用語音記帳」。停用後的新語音不會由本服務下載或送往 OpenAI，既有帳目不會因此刪除。
  • 若同意內容更新，系統會要求你重新閱讀並同意，新版本同意前不會處理語音。

圖片明細記帳

圖片功能開放後，僅供與官方帳號的一對一聊天使用。處理中可輸入「取消」；取消或停用後，較晚完成的辨識結果也不會建立候選帳目。已有待確認項目時，須先確認或取消，再傳送下一張圖片。

你可以在 LINE 輸入「啟用圖片記帳」，閱讀告知後輸入「同意並啟用圖片記帳」。圖片會送往 OpenAI 辨識；傳送前請遮住姓名、卡號、帳號及地址。原始圖片只在後端記憶體處理，不保存到本服務磁碟；第三方服務依其資料政策處理。我們不要求模型保存回應。

候選明細加密暫存，預設 30 分鐘到期；到期後立即不能確認，後端每分鐘清理過期資料。只有確認後才建立正式帳目；取消、逾期或資料不明時不入帳。正式明細依記帳保留期限保存，預設 1,095 天。圖片雜湊用於阻止完全相同圖片重複入帳，不保存原圖。

每日最多 10 次處理嘗試，每張 8 MB、40 筆，限 JPG、PNG、WebP 及台幣整數金額。日期不全、轉帳、信用卡繳款或疑似重複消費需先釐清。失敗的處理也計入當日上限；用量紀錄於次日的例行清理移除。輸入「停用圖片記帳」可撤銷後續處理；「刪除全部資料」確認後也會刪除圖片同意、用量及完整財務設定。

刪除與你的控制權

你可以刪除單筆帳目，或在 LINE 輸入「刪除全部資料」並再次確認。刪除全部資料會一併移除 LINE 記帳、ETF 部位、網頁綁定、語音同意狀態及語音用量紀錄。若需要協助，請直接透過本服務的 LINE 官方帳號聯絡。

安全設計

LINE 使用者識別以雜湊形式保存；待確認內容與已確認帳目的文字來源使用 AES-GCM 加密。系統對檔案大小、語音長度、逾時與重複訊息設有限制，但任何網路服務都無法保證零風險。
