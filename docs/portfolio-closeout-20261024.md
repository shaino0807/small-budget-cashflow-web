2. 免費登入會員可使用基本功能；付費會員由本人確認付款後手動授予 full_report，可撤銷，記錄開通者與時間。
3. 暫不接金流，不把產品的「已開通」假裝成金流已付款。
4. 先用明確標示的範例資料展示完整報告，逐項討論客戶價值、缺資料狀態及建議依據，再定免費／付費邊界。
5. 實際登入身分、管理員帳號、權限期限、跨裝置與撤銷規則需下階段確認；本輪未改權限或設定個人帳號。
