# 記帳解析、財務設定與圖片明細改善

本機修改日期：2026-09-12。此文件不代表已部署；LINE 真實圖片辨識與正式環境重開驗收尚未執行。最新交付與驗證見 [本機交付紀錄](local-release-handoff-20260912.md)。

## 多筆文字

- 多行文字先逐行解析，日期標題沿用至下一個日期；日期與玩具型號不作為金額。
- 每個非空白項目都必須能核對，最多 60 行、5,000 字；超限或有無法判斷的項目，整批不入帳並說明。
- 預覽保留原始行號（含空白行的位置）；單筆描述超過 300 字會要求拆分，不截斷後入帳。
- 同行多筆金額若交由 AI，回傳筆數必須與可辨識金額數一致；失敗不再退回只寫第一筆。
- 原 AI 的 5 筆限制改為最多 50 筆，去除 500 字截斷；超限明確拒絕。
- 顯示日期、收支、用途、金額與各類總額，輸入「確認記帳」後以單一交易寫入；任何一筆失敗都回滾。支援取消、逾期及重複確認防護。
- 信用卡帳單總付款可能與逐筆消費重複，預覽會提醒。明確的信用卡繳款／不明轉帳要求釐清。

## 商家與投資分類

- 英文商家與網址不再僅因英文片段而成為股票代號。
- Render.com、續約、訂閱的費用以生活帳單支出處理；AI 回傳服務費為 investment 時，同步修正類型、分類並清空 ticker。
- 真正 ETF 買入仍保留 investment；配息與賣出仍為 investment_income。
- 既有錯帳不會被這次程式更新自動改寫。正式修正前需讀取帳目 ID、日期、原始類型與金額，確認後更新原筆，不能另加支出而留下錯誤投資。

## 財務設定儲存

- 新增受會員 session／報告存取碼保護的 `PATCH /api/financial-settings`。
- 完整保存年度 profile、12 個月份欄位及持倉 lots；設定使用 AES-GCM 加密，與後端 profile／ETF 部位在同一資料庫交易更新。
- 前端輸入或刪除持倉後 600 ms 排程同步，保存請求依序執行。空持倉清單表示明確刪除。
- 輸入區新增「儲存全部變更」按鈕，與頁首儲存共用流程；顯示儲存中、已同步、失敗待重試或僅存於此瀏覽器。儲存中停用按鈕，避免重複送出。
- ETF 身分與「高股息」「市值型」等顯示分類分開，避免 `type === "ETF"` 漏存。
- 重新登入先載入舊報告，再以最新財務設定恢復；同帳號未同步草稿優先保留，避免被舊報告蓋回。
- 儲存失敗顯示原因，保留瀏覽器草稿；可按儲存重試。刷新回應若晚於本機修改，不套用其舊設定。
- 遠端 ETF 總額作為已同步部位的總額，不再與舊報告部位累加；一般實際記帳不覆蓋年度預算。
- `sw.js` 快取版本為 `cashflow-map-v31`，程式與樣式每次向伺服器重新驗證，不以 HTTP 舊快取代替新版。

## LINE 圖片明細

- 支援 JPG、PNG、WebP。上線開關 `LINE_IMAGE_PARSER_ENABLED` 預設 `0`；模型可由 `OPENAI_STATEMENT_MODEL` 設定，預設 `gpt-4.1-mini`。
- 啟用時由使用者先輸入「啟用圖片記帳」，閱讀第三方處理及保存說明，再輸入「同意並啟用圖片記帳」。可隨時「停用圖片記帳」。
- 原始圖片僅存在後端記憶體，透過 Responses API 的 `input_image` 送出，`store: false`。請使用者先遮住姓名、卡號、帳號、地址。
- 每人每日最多 10 次嘗試，每張 8 MB、40 筆；限台幣整數金額。下載與辨識有逾時限制。
- 候選帳目加密暫存 30 分鐘。確認前不寫正式帳本；缺日期、年份、金額、幣別、圖片裁切、不明轉帳、信用卡繳款均需釐清。
- 同圖雜湊阻擋待確認及已入帳圖片的重傳；同日、同金額的既有帳目，即使類型不同也會觸發疑似重複提醒。後者可能是合法重複消費，使用者核對後可用文字單獨記帳。
- 「刪除全部資料」與刪除帳號包含新增的圖片同意、用量及財務設定。
- 尚未包含 PDF、Excel、跨幣別換算及免確認自動入帳。

2026-09-12 補強：圖片下載與確認限一對一聊天；開關在下載、辨識回傳與確認時再次檢查。處理中建立請求標記，取消／撤銷後的較晚回應不可重建候選帳目；有待處理項目時阻止其他圖片覆蓋。辨識錯誤不回傳內部訊息，模型警告不原樣轉發。拒絕檔案格式偽裝、缺完成狀態、非字串或過長描述、明顯帳號／卡號及規則判定的繳卡費／轉帳。相同圖片與同張明細的同日同額均攔截；描述規則並不保證辨識所有個資，仍須使用者事先遮蔽與逐筆核對。

過期候選立即不可確認；後端每分鐘清理過期資料。用量紀錄按台灣日期清理。Pages 與後端共用公開檔案白名單，後端程式、私密設定、資料庫、測試腳本及報告不作為公開靜態檔案。

API 格式參考：[OpenAI Responses API](https://developers.openai.com/api/reference/cli/resources/responses/methods/create)。`store: false` 不等同對第三方所有資料保留政策作出零留存承諾。
