# 圖片補資料對話與多筆語音記帳

## 行為

- 圖片幣別回傳使用固定列舉，並兼容 TWD、NTD、NT$、台幣等寫法；未標示保持 unknown，外幣不自行換算。
- 辨識警告使用固定原因碼。缺年／幣別由實際交易欄位驗證並詢問；裁切、不可讀、未知警告仍阻止入帳，不能把未辨識完整的帳單放行。
- 先列完整可見商家、用途、金額，再直接問年份與幣別，接受「全部為 2026 年」「都是台幣」分次回答。只缺年／幣別的草稿加密保存，回答時不重送 OpenAI。
- 依本次使用者要求，先明確告知「補齊即代表確認上列明細」，補齊後重驗、查重，整批入帳；任何疑慮或失敗皆不寫入部分帳目。舊版已建立、未包含此告知的草稿仍保留確認步驟。
- 語音可包含多筆。使用明確說出的日期作為後續項目的日期，遇到下一個明確日期則切換。支援逗號、常見連接詞，以及常見用途緊接金額的句子。一次列明細／合計，再確認一次寫入全部項目。
- 「今天停車花一百八，晚餐花一百八」為交通 180、伙食 180，共 360；同日同額但不同用途不合併。多個用途只有一個金額仍詢問歸屬；缺資料的段落逐段指出，整批不先入帳。
- 多筆語音使用既有加密 voice_confirmation 草稿；確認時檢查啟用旗標與同意版本，原子交易寫入，重播不重复轉錄／入帳，按錯整批撤銷。
- 超過 500 字的轉錄或超過 40 筆明細明確拒絕，不截斷。
