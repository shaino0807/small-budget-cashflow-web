# 會員導覽與完整報告入口修正

問題：主要 App 導覽曾被 CSS 移到畫面外；已開通會員仍看到升級 CTA，報告載入中也標成未解鎖。頁面切換未同步 URL，造成後台網址與實際畫面不同。

修正：登入並完成健檢後，顯示固定的本月總覽、收支摘要、完整報告導覽；管理員另有管理員後台。完整報告提供資產模擬與現金流月曆入口。切頁更新 URL，支援返回、前進與重新整理。受限頁面等候後端權限確認，後發的導航優先。已開通會員的報告 CTA 直接進完整報告。

網路或 5xx 錯誤清除舊規劃資料並提供重試，不據此撤銷會員身分。401/403 仍失敗關閉；真正的會員與資料權限由既有後端執行。報告載入、暫時失敗和未開通分別顯示。未改正式管理員、會員資料、付費範圍或期限。

本地驗證：7 項導航單元情境、40 項會員 API 檢查與既有 ledger regression 通過。CUA 以合成帳號實際操作 1440、390、320 像素：管理員來回導航、已開通 CTA、返回/前進/重新整理、免費/付費/訪客界線、503 與重試、鍵盤 Tab/Enter；320 像素無水平溢出，導覽高度至少 44px，文字對比至少 9.7:1。瀏覽器尺寸模擬不代表實體手機驗證。

CI 增加導航測試，會員瀏覽器測試要求導航位於視窗內且可命中；不再僅靠程式 click 驗證畫面外按鈕。正式上線與登入驗收結果另留本地交付紀錄。
