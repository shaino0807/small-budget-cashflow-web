## 客戶看到的改變

1. 家庭收支可輸入數字代號，或輸入中文名稱再從主檔建議選擇。唯一名稱會轉成代號；名稱有多筆結果時不猜選。
2. ETF 殖利率由「最近 12 個月已發放的每單位配息合計 ÷ 最新有日期收盤價」計算，顯示配息統計截止日及價格交易日。ETF 欄位唯讀；完整配息或價格不足時保留空值及「待補」，相關配息金額標示只計已知部分。官方明確不配息時才可顯示 0%。上市未滿一年另行標示，不按配息次數推估年化。
3. 價格走勢可加入、移除主檔 ETF，或使用「我的持有 ETF」，並選擇近 1、3、6 個月。價格以共同交易日起點 100、實際日期作為橫軸；缺價格或共同日期時清楚提示，清空選擇會清除舊圖。比較標的可以不同於持有標的。
4. 成分股族群、完整成分股、價格明細及 NAV 明細依家庭收支持有的 ETF 篩選。每個持有標的預設展開，取消原本 80 檔成分股及 18 筆價格的截斷。沒有來源時保留該 ETF 並顯示資料待補。
5. 主檔的「官方資料日」「最後成功取得時間」「價格交易日」分開呈現。官方主檔端點沒有日期時顯示「官方未提供」，不填入今天，也不直接顯示 `null`。

## 實作與驗證

新增公開市場資料查詢 `GET /api/market/etf?ticker=0050&months=1`。查詢只送 ETF 代號及價格期間，不傳家庭持有金額、帳號或客戶資料到投信；不 dispatch 發布流程、不重寫正式主檔。客戶開啟頁面或按「重新讀取」只查詢快照與所選公開資料，移除舊前端自動觸發整庫更新／Pages workflow 的呼叫；既有後台更新 API 與排程維持原狀。快取只存公開市場資料，15 分鐘有效、同代號請求合併、最多同時 2 個來源查詢，HTTP 每 IP 有次數限制。來源失敗保留原快照及原成功資料時間；不同基金身份、缺漏持股及不完整配息歷史拒絕取代已驗證資料。

本機 Node **26.1.0**；Node 22 的正式 CI 結果應以此 PR 對應 head 的 GitHub Actions 為準，本機通過不代替 CI。CI 使用既有 Windows／Node 22 工作流程，沒有安裝依賴。本次新增與擴充的驗證包括：

- 31 個數值／日期案例：跨月、跨年、閏日、完整 12 月窗口、重複／未發放／缺日期配息、缺價格、名稱歧義與已知分割。
- 公開快取的持久化、重啟、來源失敗保留資料與日期、不覆寫主檔／客戶資料、不同基金身份拒絕。
- 每檔 100 筆的合成 UI 案例，驗證兩檔合計 200 筆未截斷；這是回歸測試資料，不是官方實際持股數。
- 390×844 與 1440×900 瀏覽器流程：中文名稱、自動帶入唯讀殖利率、持有／比較分開、資料缺漏及清空狀態、焦點、零水平溢出、既有帳本與財務資料保存。
- 官方 0050／0056 在本機瀏覽器實際操作：各 50 檔預設展開、各 26 筆價格、殖利率 1.39%／7.00%。鍵盤 Tab 可到加入比較按鈕，焦點可見。新增控制項沒有新增動態效果，沿用既有減少動態設定；尚未驗證真機及螢幕閱讀器。

本地證據在 `webapp/reports/etf-customer/`：官方 HTML／JSON、`official-verification.json`、最終回歸日誌、手機及桌機 JPG。此目錄為 Git 忽略檔，不在 PR 中。

首輪 Node 22.23.3 CI 的數據與後端測試成功，但瀏覽器首頁就緒逾時。功能測試現隔離 Google Fonts 的外部請求，避免把外部字型連線狀態當成本機功能依賴；僅忽略已刻意封鎖的字型請求，產品檔案及 API 失敗仍使驗收不通過，逾時另輸出載入診斷。實際字型與品牌畫面以 CUA 瀏覽器的桌機／手機視檢證據驗收，CI 不宣稱外部字型服務可用。最終 CI 狀態以 PR #10 最新 head 對應的 Actions 為準。
