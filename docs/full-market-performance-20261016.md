## 程式變更

- 客戶讀取精簡目錄及持有／選取 ETF 的保存明細；跨站後端時優先使用同站靜態資料；不在客戶請求內抓官方網站。背景更新通過檢查後才替換批次，來源失敗保留前次資料。
- 完整 JSON 使用精簡格式，目錄與逐檔靜態資料共用同一 batchId。混用批次會拒絕並要求重新讀取；診斷端點仍獨立驗證磁碟內容。
- 官方來源加入各投信完整公開資產表及配息歷史；公告生效日、持倉日、NAV 日與取得時間分開。匿名網站會話只保留於記憶體，憑證不寫入回執或 Git；部分 HTML 的隱藏表單值會移除並另留傳輸雜湊。
- 來源受限時停止請求並保存冷卻時間，不繞過 Access Denied、CAPTCHA 或 TLS 檢查。既有系統 curl 僅用於公開匿名 GET、保留憑證驗證。
- 殖利率核對實際付款、除息日期、重複事件、幣別與完整窗口；官方資料矛盾時阻擋。分割以除息時單位換算，反分割保留公告整數比例，價格比較亦處理分割。
- 跨日／跨月沿用保存批次時保留原統計日，超過既有三日時效不繼續沿用殖利率。不把執行日當成官方資料日。
- 股票主檔不再把債券、現金與衍生商品當成股票；資料摘要顯示整批已收錄筆數，不把延後載入顯示為 0。基本資料出表日使用官方主檔欄位，未提供者保留未知。

FinMind 維持先前 0050／0056 小範圍比對，未改為本批全市場正式來源。第 11 項採用的是批次資料管理方法，並未因此改用 PostgreSQL。推薦清單第 12、13、14、17 項未採用。
